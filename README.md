# TODO Микросервис на Go

Простой RESTful микросервис для управления списком задач (TODO) без авторизации. Предназначен для одного пользователя. Использует PostgreSQL в качестве базы данных и GORM в качестве ORM.

---

## Технологии

- **Язык**: Go (Golang)
- **Веб-фреймворк**: Gin
- **ORM**: GORM
- **База данных**: PostgreSQL
- **Hot Reload**: Air (для разработки)
- **Утилиты**: `curl`, `jq` (опционально, для форматирования JSON)

---

##  Быстрый старт

### 1. Требования

- Go 1.20+
- PostgreSQL 12+
- `make` (обычно предустановлен в Linux/macOS)

### 2. Установка зависимостей

```bash
go mod tidy
```

### 3. Настройка базы данных

Создайте базу данных в PostgreSQL, например:

```sql
CREATE DATABASE todo_db;
```

Затем создайте файл `.env` в корне проекта:

```env
DB_HOST=localhost
DB_USER=postgres
DB_PASSWORD=yourpassword
DB_NAME=todo_db
DB_PORT=5432
```

> Замените `yourpassword` на ваш реальный пароль от PostgreSQL.

### 4. Установка Air (для разработки)

```bash
go install github.com/cosmtrek/air@latest
```

Убедитесь, что `$GOPATH/bin` добавлен в ваш `PATH`.

### 5. Запуск

#### В режиме разработки (с hot reload):

```bash
make dev
```

Сервер будет доступен на `http://localhost:8080`.

#### В обычном режиме:

```bash
make run
```

---

## Тестирование через cURL

После запуска сервера в другом терминале выполните:

```bash
make test-curl
```

Эта команда последовательно:

1. Получает список задач (изначально пуст)
2. Создаёт две задачи
3. Получает, обновляет и удаляет задачи
4. Проверяет финальное состояние
---

## API Endpoints

| Метод   | Путь             | Описание                     |
|---------|------------------|------------------------------|
| GET     | `/todos`         | Получить все задачи          |
| GET     | `/todos/:id`     | Получить задачу по ID        |
| POST    | `/todos`         | Создать новую задачу         |
| PUT     | `/todos/:id`     | Обновить задачу по ID        |
|  DELETE | `/todos/:id`     | Удалить задачу по ID         |


### Формат задачи (JSON)

```json
{
  "title": "Название задачи",
  "description": "Описание (опционально)",
  "done": false
}
```

Поля:
- `title` — обязательное, строка
- `description` — необязательное, строка
- `done` — булево, по умолчанию `false`
